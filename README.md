# greek-app - аудиокурс греческого для себя

Отдельная область, к Cocktail Ceremony не относится. Живёт в этом репо рядом с
`bartender-app/` просто потому, что здесь рабочая папка.

Цель: личный курс на **1000 слов повседневной жизни** на Кипре, слушается с занятыми
руками. Пять тем: база, магазин, ресторан, госучреждение, транспорт.

## Что читать в каком порядке

| Файл | О чём |
|---|---|
| `METHOD.md` | Методика по убыванию эффекта. Главное: **пауза перед ответом**, а не после. |
| `COURSE.md` | Раскладка 1000 слов по темам и пакетам, измеренная арифметика урока. |
| `TAPS.md` | Касания наушника; двойное = «не понял». Диктует архитектуру - читать до кода приложения. |
| `prototype/index.html` | Дизайн-эталон: 4 экрана, живой плеер. Палитра и шрифты - оттуда. |

## Как поклацать

**С ноутбука:** открой с диска `app/index.html`. Играет настоящий урок, такты
подсвечиваются, «пульт наушника» под телефоном работает с клавиатуры: **пробел** -
пауза, **D** - двойное касание, **R** - тройное.

**С телефона:** `app/phone.html` - один самодостаточный файл (6.8 МБ): урок на 10 минут,
шрифты и данные запечены внутрь, внешних запросов ноль, интернет не нужен. Собирается
`python3 tools/build_phone.py`. Двадцати- и сорокаминутные уроки туда не влезают
(9.6 и 19 МБ аудио) - для них нужен обычный хостинг с поддержкой Range-запросов.

## Генератор

```bash
python3 tools/verify_content.py 'content/*.json'      # проверить контент
python3 tools/build_audio.py --course content/course.json   # собрать 10, 20 и 40 мин
python3 tools/build_app_data.py                       # данные для приложения
python3 tools/test_app.py                             # проверить приложение
```

Порядок именно такой: аудио → данные → тест. Приложение читает `app/data.js`, а не
манифесты напрямую, потому что открывается с диска, где `fetch` JSON запрещён.

Собирает из JSON аудиофайл с паузами. Что кладёт в `build/`:

| Файл | Зачем |
|---|---|
| `<pack>.mp3` | урок (64 kbps моно - речь, вес важнее качества) |
| `<pack>.timings.json` | тайминги каждого слова и каждого такта; по ним касание находит слово |
| `<pack>.txt` | текстовая расшифровка |
| `.cache/` | клипы TTS по хэшу: пересборка пакета - 12 секунд вместо 2.5 минут |

### Флаги

```
--course FILE      файл курса: уроки из общего потока уникальных слов
--only ID          собрать урок, начинающийся с этого пакета
--tier 10|20|40    какие длины собирать (по умолчанию все три)
--marked FILE      слова, отмеченные двойным касанием - разогревом в начало урока
--out DIR          куда складывать (по умолчанию build/)
--cache DIR        кэш клипов (по умолчанию build/.cache, общий для всех --out)
--format mp3|m4a|wav
--dry-run          показать состав без синтеза
```

Длина урока точная: 10:00 / 20:00 / 40:00. Слова берутся из потока, пока влезают
(41 / 82 / 163 штуки), остаток меньше одного слова растягивается по паузам. **Повторов
внутри урока нет** - если контента в потоке не хватило, урок честно короче и генератор
об этом пишет.

### Схема элемента

```json
{
  "id": "psomi",
  "gr": "Ψωμί",
  "ru": "хлеб",
  "tr": "psomí",
  "forms": ["ψωμί", "ψωμιού", "ψωμιά"],
  "phrase": "Πόσο κάνει το ψωμί;",
  "phrase_ru": "Сколько стоит хлеб?"
}
```

`id` обязателен по смыслу: он связывает слово между пакетами, чтобы «не понял» на
всплывшем повторе попало в то же слово (`TAPS.md`). `forms` - формы, в которых слово
реально звучит; без них курс не работает на слух, потому что язык флективный.
`audio` - готовая запись вместо синтеза, по роли: `{"gr": "rec/psomi.m4a"}`. Это путь
для кипрского, который не умеет ни один TTS.

### Такты схемы (`pattern`)

| Токен | Что делает |
|---|---|
| `gr` / `ru` | слово и перевод |
| `gr_slow` | слово медленно |
| `forms` | формы подряд, одной репликой; шаг сам выпадает, если форм нет |
| `phrase` / `phrase_ru` | фраза и её перевод |
| `phrase_fast` | фраза на нормальной скорости (финальный проход) |
| `pause:auto*1.6` | пауза на припоминание: от длины последней реплики, не короче 1.8с |
| `pause:2.5` | фиксированная пауза |
| `gap` / `gap:0.5` | склейка между тактами |
| `tone` | короткий сигнал |

Три схемы на пакет: `pattern` (новое слово), `review_pattern` (слово, отмеченное
касанием - короткий цикл без фразы), `final_pattern` (финальный проход на нормальной
скорости). Дефолты - константы `FULL_CYCLE` / `REVIEW_CYCLE` / `FINAL_CYCLE` в коде.

Финальный проход - единственное место, где фраза звучит дважды. Это осознанно: «две
скорости» из `METHOD.md` борются со слипанием речи. Не нужен - поставь
`"final_pattern": []` в пакете.

Всё валидируется до синтеза: неизвестный такт, элемент без нужного поля, пустая схема,
опечатка в имени ключа (в пакете и в файле курса), отсутствующий системный голос.

### Приложение

`app/index.html` - те же четыре экрана прототипа, но рабочие. Что в нём живое:

- **плеер синхронизирован с MP3** по манифесту таймингов: пять клеток метра
  подсвечиваются по такту, в паузе на экране висит то, что надо вспомнить;
- **кнопки 10 / 20 / 40** переключают настоящие уроки;
- **касания наушника**: двойное = «не понял» (аудио не прыгает, слово падает в список),
  тройное = повтор слова с начала цикла. Перехват через `navigator.mediaSession`,
  плюс кнопки и клавиши для ноутбука;
- **экран «Повтор»** собирает отмеченное и выгружает `{"ids": [...]}` для `--marked`;
- **транскрипция по слогам** под словом: `ψωμί` → `псо-МИ`, ударный слог заглавными.
  Считается автоматически (`tools/translit.py`), поле `syl` в контенте перебивает расчёт;
- **настройка касаний** на экране «Я»: двойное и тройное касание переназначаются
  (не понял / промотка / повтор), звук подтверждения отключается. Хранится в браузере.
  Одиночное касание всегда пауза - рефлекс не переназначаем;
- **локскрин** с греческим словом, транскрипцией и переводом - экран 3 прототипа.

`tools/test_app.py` гоняет это в Chromium: 36 проверок, включая сверку каждого такта и
транскрипции с манифестом. Тестовый сервер отдаёт Range-запросы - без них Chromium не умеет
перематывать аудио, и половина проверок ложно падает.

### Транскрипция по слогам

`tools/translit.py` переводит греческое слово в русские слоги с ударением:
`ψωμί` → `псо-МИ`, `Εντάξει` → `эн-ДА-кси`, `Αύριο` → `АВ-рьо`. Правила: гласные и
согласные диграфы, двойные согласные как одна, озвончение смычной после назала,
`σ` перед звонкой как «з», синизис (`δουλειά` → `ду-ЛЯ`), тонос задаёт ударный слог.

```bash
python3 tools/translit.py            # самопроверка на 31 эталонном слове
python3 tools/translit.py Ψωμί Νερό  # посмотреть конкретные слова
```

Правила приближённые. Слово, где алгоритм врёт, правится полем `syl` в контенте -
оно перебивает расчёт.

### Проверка контента

`verify_content.py` ловит то, что глазами не видно: смешанные алфавиты (греческая `ε`
внутри русского слова - я сам так ошибся при переносе прототипа), пропущенный тонос в
многосложном слове, фразу без самого слова, дубли id между пакетами, `forms` не списком.

## Зависимости

Стандартная библиотека Python + macOS `say` и `afconvert`. Из внешнего - только энкодер
MP3, потому что CoreAudio умеет MP3 читать, но не писать:

```bash
python3 -m pip install --user lameenc
```

Уже поставлено (`lameenc 1.8.1`). Скрипт подхватит `ffmpeg` или `lame`, если появятся;
не найдёт ничего - соберёт `.m4a` и скажет об этом.

## Голос

Генератор сам берёт **лучший установленный вариант**: `Melina (Premium)` →
`Melina (Enhanced)` → `Melina`. Ничего настраивать не нужно, достаточно пересобрать.

Сейчас установлена только компактная `Melina` - конкатенативный голос, звучит роботом.
Улучшить её нечем: проверял, пунктуация и скорость на естественность не влияют, вывод
получается байт-в-байт одинаковый.

**Естественный греческий голос на этой машине - один: `Melina (Premium)`, 241 МБ.**
Ставится вручную (я системные настройки не меняю):

> System Settings → Accessibility → Spoken Content → System Voice → Manage Voices →
> Ελληνικά → Melina (Premium)

После установки:

```bash
python3 tools/build_audio.py --course content/course.json && python3 tools/build_app_data.py
```

Кэш клипов привязан к имени голоса, так что старые файлы не помешают - всё
пересинтезируется заново (~4 минуты на три урока).

Альтернатива без загрузки 241 МБ - облачный **Google WaveNet**: $4 за млн символов при
бесплатном лимите 4 млн в месяц, то есть весь курс на 1000 слов бесплатно (расчёт в
`METHOD.md`). Нужен ключ Google Cloud и слой в `tts_clip` вместо `say`.
