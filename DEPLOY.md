# Выкладка на GitHub Pages

Выбрано 2026-08-18. Netlify отпал: лимит исчерпан.

**Учти:** на бесплатном тарифе GitHub репозиторий публичный. Курс, аудио и прогресс
будут доступны любому по ссылке. Приватный репозиторий с Pages - это платный тариф.

## Что делаю я

```bash
python3 tools/build_app_data.py      # данные из манифестов
python3 tools/build_site.py          # папка site/: приложение + аудио
```

`site/` - это готовый статический сайт: `index.html`, `data.js`, `audio/*.mp3`
и `.nojekyll` (без него Pages прогоняет файлы через Jekyll и может их съесть).

## Что делаешь ты (один раз)

Пуш требует твоей авторизации - в чужие аккаунты я не вхожу и токены не ввожу.
На машине нет ни `gh`, ни SSH-ключей, ни сохранённого доступа к GitHub.

**1. Представься гиту** (если ещё не):

```bash
git config --global user.name "Danil"
git config --global user.email "твоя@почта"
```

**2. Создай пустой репозиторий** на github.com - например `akou-greek`.
Без README, без .gitignore.

**3. Отправь код** (я подготовлю коммит, тебе останется push):

```bash
cd greek-app && git remote add origin https://github.com/ТВОЙ_ЛОГИН/akou-greek.git && git push -u origin main
```

При первом пуше GitHub попросит логин и токен - вводишь ты, в своём терминале.

**4. Включи Pages:** Settings → Pages → Source: `main`, папка `/site` → Save.

Через минуту сайт будет на `https://ТВОЙ_ЛОГИН.github.io/akou-greek/`.

## Ограничения, о которых надо знать заранее

| Что | Предел | Нам хватает? |
|---|---|---|
| Размер файла | 100 МБ | часовая сессия ~29 МБ - да |
| Размер репозитория | 1 ГБ (мягкий) | ~34 часа аудио - да |
| Трафик | 100 ГБ/мес (мягкий) | для одного человека - с запасом |

Аудио тяжёлое, поэтому в репозиторий идут **только собранные сессии**, а не кэш
клипов и не WAV. Это уже прописано в `.gitignore`.

## Обновление

```bash
python3 tools/build_session.py --minutes 120 --review 60
python3 tools/build_app_data.py && python3 tools/build_site.py
git add site && git commit -m "новая сессия" && git push
```

Pages подхватит изменения сам за минуту.
