# Методика. Что и почему, по убыванию эффекта

Источник: разбор из диалога, перенесённый в репо 2026-08-17. Это рабочий канон -
генератор и курс собираются по нему.

## Главная правка к прототипу

Пятитактный цикл в прототипе (`prototype/index.html`) - это **предъявление, а не
извлечение**. Мозг просто слушает. Память строит усилие вспомнить, поэтому:

> **Пауза стоит ПЕРЕД ответом, а не после.**
> `ψωμί` … (2 сек тишины, вспоминаешь) … `хлеб`

Вслух говорить не обязательно, мысленно работает так же. На этом построен весь Пимслер.

Такой цикл (тактов по-прежнему пять, пауза живёт внутри первого):

```
ΓΡ  →  [пауза 2с: вспомни]  →  RU  →  ΓΡ  →  фраза ΓΡ  →  [пауза]  →  перевод фразы
```

**Следствие для прототипа:** подсказка в плеере «слушай, не повторяй вслух»
противоречит исправленному методу. Она должна стать «вспомни перевод». Правку в
`prototype/index.html` пока не внёс - это дизайн-эталон в том виде, в котором он был
показан; менять его надо осознанно.

## Дальше по силе эффекта

**1. Повтор только по запросу, автоматического нет.** Решение от 2026-08-17:
**внутри урока каждое слово звучит один раз**, уроки состоят из уникальных слов.
Слово возвращается лишь тогда, когда человек отметил его двойным касанием - оно
идёт разогревом в начало следующего урока (`--marked`).

Это отменяет более раннюю схему с расширяющимися интервалами (70% новых + 30%
всплывших из N−1, N−3, N−7, N−16): она была реализована и работала, но заменена
осознанно. Причина: набивка урока повторами ради длины даёт до восьми проходов по
одному слову за урок, а адаптивный повтор по касанию точнее - возвращается ровно
то, что человек не узнал.

**2. Две скорости.** Стена «слова знаю, речь не понимаю» - это не словарь, а слипание
слов в потоке. **Последний проход каждого пакета идёт на нормальной скорости**, без
дидактического замедления.

**3. Двойное касание наушника = «не понял».** Единственная интеракция, доступная с
занятыми руками. Слово падает в завтрашний повтор. Превращает фиксированный плейлист
в адаптивный - этого нет ни у кого. Детали в `TAPS.md`.

**4. Греческий слой, который уже есть в русском.** Не выдуманные мнемоники, а реально
существующие связи: `γάλα` - молоко (галактика), `φωτιά` - огонь (фото), `καρδιά` -
сердце (кардио), `τράπεζα` - банк (трапеза), `βιβλίο` - книга, `ζώο` - животное
(зоопарк), `χρόνος`, `ιδέα`, `θέατρο`, `πρόβλημα`, `μηχανή`, `αέρας`. Это 200-300 слов,
которые не надо учить - надо показать. Отдельный первый пакет: «Ты уже знаешь 200
греческих слов». Он и учит, и снимает страх.

**5. Придуманные мнемоники - только точечно.** (`σπίτι` - «спи ты» = дом.) Работают, но
дороги в производстве и очень личные. Не на все 1000, а на те 20-30% слов, которые
реально не липнут. Кто именно не липнет - видно по данным: слово, на котором чаще всего
жмут «не понял».

## Сколько слов что даёт

Доля звучащей речи, которую покрывает словарь (разговорный язык, не письменный):

| Слов | Покрытие | Ощущение |
|---|---|---|
| 300 | ~50% | ловишь отдельные слова |
| 1000 | ~78% | выцепляешь смысл простого бытового обмена |
| 2000 | ~86% | |
| 3000 | ~90% | |
| 5000 | ~94% | |
| 8-9 тыс. | ~98% | просто слушаешь |

**Честность:** 78% ≠ «понял на 78%». Это одно незнакомое слово примерно в каждом
предложении, субъективно - «понял половину». Комфорт начинается с 95%+. Поэтому 1000
слов - это не «понимаю греческий».

**Ключевой вывод: узкое покрытие сильнее широкого.** 150 слов темы «рынок» дают ~90%
реплик на рынке. Знающий 300 слов по трём своим темам чувствует себя лучше, чем знающий
1000 вразброс. Отсюда и тематическая структура курса.

## Греческая специфика: формы, а не леммы

Язык сильно флективный. 1000 лемм = **3000-4000 звучащих форм**. На слух другая форма =
другое слово. Значит слово надо давать в тех формах, в которых оно реально звучит
(`νερό` / `νερού` / `νερά`), а не только в словарной. Это +30% к контенту, но без этого
курс не работает именно на слух.

В схеме контента это поле `forms` у элемента.

## Производство звука: деньги и решения

Один цикл на слово ≈ 110 символов (слово + перевод + повтор + фраза + перевод). Курс на
1000 слов с двумя фразами, двумя голосами и двумя скоростями, с запасом на
перегенерацию: **~1-1,2 млн символов**.

| Движок | Цена за 1 млн символов |
|---|---|
| Google Standard / WaveNet | $4 (WaveNet подешевел в начале 2026) |
| Google Neural2 | $16 |
| Google Chirp 3 HD | $30 |

У Google постоянный бесплатный лимит **4 млн символов в месяц** на Standard и WaveNet -
то есть весь курс на 1000 слов укладывается в бесплатный лимит. Даже 5000 слов на
топовом Chirp 3 HD - около $180 разово. ElevenLabs дороже на порядок и по подписке, а для
греческого его качество не факт что выше.

**Два практических момента:**

- **SSML тарифицируется как символы.** Паузы через `<break time="2s"/>` съедят половину
  бюджета. Тишину вставлять пост-обработкой. В нашем генераторе так и сделано, причём на
  чистой stdlib (`wave`, `array`), без pydub и ffmpeg.
- **Кипрский диалект не умеет ни один TTS.** Главное отличие продукта придётся писать
  живым голосом. В Лимассоле это решается за небольшие деньги и выйдет лучше синтеза.
  Заложено в план сразу: генератор должен уметь брать готовый файл вместо синтеза
  (поле `audio` у элемента), иначе живые записи некуда будет вставить.

## Что из этого уже в генераторе, а что нет

| Пункт | Статус |
|---|---|
| Пауза перед ответом | есть (схема `pattern`) |
| Пятитактный цикл со фразой | есть |
| Две скорости, финальный проход | есть (`final_pass`) |
| Тишина пост-обработкой, не SSML | есть |
| Уроки из уникальных слов, без набивки | есть |
| Повтор по двойному касанию (`--marked`) | есть в генераторе, отдаётся из приложения |
| Точная длина 10 / 20 / 40 минут | есть (остаток растягивается по паузам) |
| Формы слова | есть (поле `forms`) |
| Готовые записи вместо синтеза | нет, нужно для кипрского |
| Автовыбор лучшего системного голоса (Premium → Enhanced → компакт) | есть |
| Естественный голос | нет: Melina (Premium), 241 МБ, ставится вручную |
| Google TTS вместо системного `say` | нет, нужен ключ Google Cloud |
| Мнемоники по данным «не понял» | нет, нужны данные из приложения |
